# Mega Facepack V2 — paquet STRYKER

Ce dossier décrit le paquet propre destiné au stockage distant STRYKER. Le script de préparation ne conserve que les dossiers `#Win` utilisés par le jeu et les place sous :

```text
livecpk/MEGA_FACEPACK_V2/Asset/model/character/face/real/<player-id>/#Win
```

Les dossiers `sourceimages`, journaux, sauvegardes et scripts de travail de l’archive d’origine ne sont pas redistribués. Les fichiers `Faces.txt` et `Creditos.txt` doivent rester dans la racine du paquet final.

La fiche peut être présentée sur le site, mais l’archive ne doit pas être publiée tant que le droit de redistribution des créateurs crédités n’a pas été confirmé.
